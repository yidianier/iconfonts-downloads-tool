## Iconpack v1.1.0

一个开源 Chrome 插件，在紧凑窗口中批量下载 iconfont 图标库。

### 功能

- 识别任意可访问图标库，支持链接或库 ID。
- 搜索、全选、反选和只看已选。
- SVG / 透明 PNG，32–1024 px，原色或自定义单色。
- 自定义 ZIP 名称、进度反馈、取消及失败项重试。
- 全部本地打包，附图标来源记录；源码采用 MIT 许可证。

### 安装

1. 下载本页 Assets 中的 `iconpack-1.1.0.zip` 并解压。
2. 打开 `chrome://extensions/`，启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择解压后包含 manifest.json 的文件夹。
4. 刷新 iconfont 图标库页面，点击右下角“批量下载”或工具栏 Iconpack。

详细使用说明与操作截图：[README](https://github.com/yidianier/iconfonts-downloads-tool#readme)。

`SHA256SUMS.txt` 提供安装包校验值。图标素材遵循原作者授权，不受插件 MIT 许可证覆盖。

基础测试、语法检查、434 个图标的整库导出和紧凑窗口交互已验证。当前未上架 Chrome Web Store。
